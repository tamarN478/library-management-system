# Library Management System

A Python-based Object-Oriented Library Management System that handles catalog management, membership tracking, purchases with dynamic discounts, loans, reservations, and fine calculations.

## Features

- **Inventory Management**: Add and remove book titles along with stock quantities.
- **Membership Benefits**: Registered members automatically receive a 25% discount on book purchases.
- **Borrow & Return**: Tracks active borrows and dynamically updates inventory.
- **Reservations**: Allows users to reserve titles.
- **Fine Calculation**: Computes overdue charges ($1.00/day) for late returns.

## How to Run

```bash
python library.py
